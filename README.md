# TravelMS

This project was created using [Angular CLI](https://github.com/angular/angular-cli) version 21.1.4.

## Development server

1. open powershell / two tabs
2. first tab 
    cd "~directory" 
    npm install
    ng serve (port 4200)
2. second tab
    cd "~directory" 
    node server.js (port 3300)

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
